# Contradiction and Uncertainty Register

1. **Five-dimensional mapping** — Proposed, not established. Current strongest mapping:
   Phonology→Movement; Morphology→Evolution; Syntax→Design; Semantics→Being; Pragmatics→Space.
   Main rival pressure point: morphology and syntax both participate in composition, so some theories distribute "Design" across morphosyntax.
2. **Scale-invariant phonology** — Below/above sound scale, "phonological function" must be understood abstractly as contrast/realization/sequencing, not literal acoustics. This is a structural analogy.
3. **Semantics at binary-state level** — A six-bit pattern has mathematical identity but no intrinsic natural-language or biological meaning. Traditional Yijing semantics are historically supplied, not derived from the bits.
4. **Codon mapping** — 64↔64 cardinality is exact; a unique one-to-one biological mapping is not. Any bijection requires a coding convention.
5. **Transition legality** — The Q6 single-line-flip graph is a clean primitive grammar, but traditional Yijing practice may license compound changes involving multiple lines. Those should be represented as compound operators, not confused with primitive edges.
6. **Higher-order sequence grammar** — The existence of a 64-state alphabet does not by itself prove phrase/clause-like higher syntax. This must be tested against an independently specified corpus or operational semantics.
7. **Emergent grammar** — Usage-based emergence is compatible with recursive state learning, but it does not imply a fixed five-axis ontology.
